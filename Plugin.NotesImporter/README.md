# Plugin.NotesImporter (library)

The Plugin.NotesImporter class library: imports Apple Notes, Google Keep and Microsoft OneNote exports
into a unified, serializable `Note` model (text + Base64 images + timestamps), with sync and async
APIs.

See the [repository README](../README.md) for usage and [docs/FORMATS.md](../docs/FORMATS.md) for
the export formats each importer reads.
